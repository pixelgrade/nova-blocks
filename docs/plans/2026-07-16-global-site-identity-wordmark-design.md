# Global Site Identity Wordmark Design

## Objective

Let people reproduce editorial mastheads such as Hive using the semantic WordPress Site Title and Site Tagline blocks, while preserving the existing image-logo workflow.

The first version adds three reusable visual capabilities:

1. A Site Title can behave like a wordmark: one line, responsive Fit Text, and a controlled maximum width.
2. A Site Tagline can become a ruled label with flexible lines on either side.
3. A Header Row can draw a subtle rule above navigation.

These capabilities are global block enhancements. The Hive-like header is one composed recipe, not a special-purpose Hive block.

## Product Principles

- Keep content semantic. The title remains `core/site-title` and the tagline remains `core/site-tagline`.
- Reuse native WordPress controls. Nova enables WordPress core's Fit Text typography support on Site Title instead of introducing a second fitting algorithm.
- Keep typography ownership in Style Manager and Global Styles. Nova supplies layout behavior and consumes the existing semantic site-title variables where available.
- Store only durable user choices. The wordmark width is an explicit block attribute; the fitted font size remains derived by core.
- Preserve old headers. Existing `core/site-logo` and `novablocks/logo` markup and behavior are untouched.
- Favor responsive fallbacks. A wordmark is capped by its requested width and by the available inline space, so it cannot force horizontal overflow.

## Block Model

### Site Title

Nova extends `core/site-title` with:

- native typography `fitText` support;
- a `fitTextWidth` number attribute, defaulting to 395 pixels;
- a Wordmark block style;
- a Wordmark Width dimensions control shown when Fit Text is active.

The width is a maximum inline size, not a fixed viewport size. The Site Title remains visible if JavaScript or the Interactivity API is unavailable; only the automatic fitting behavior degrades.

The Wordmark style provides single-line wordmark mechanics and consumes Style Manager's semantic site-title variables. Explicit block typography remains able to override those inherited defaults.

### Site Tagline

The Ruled Label style renders the tagline as a centered flex row with generated lines before and after the text. The lines use `currentColor`, so they follow the contextual color system automatically.

### Site Identity

`novablocks/site-identity` is a small semantic composition block containing a Site Title and optional Site Tagline. It owns a shared `identityWidth` attribute, defaulting to 395 pixels, so title and tagline can align to the same visual measure.

The block root remains full-width for Header Row alignment. Its inner container applies the shared maximum width. The root also carries the existing `c-branding` hook so Nova's desktop and mobile header behavior recognizes it as the brand element.

### Header Row

The Rule Above style draws a one-pixel rule across the Header Row inner container. It uses `currentColor` with reduced opacity and does not introduce a new color setting.

## Editorial Masthead Recipe

The Header Design chooser gains an Editorial Masthead layout:

- first row: centered Site Identity;
- Site Title: Wordmark style, native Fit Text enabled, negative letter spacing, bold uppercase typography;
- Site Tagline: Ruled Label style, uppercase tracking;
- second row: centered primary navigation with Rule Above.

The recipe supplies a Hive-like starting point, while every part remains editable through native block controls.

## Data Flow

1. The Site Identity width controls the shared visual container.
2. Site Title Fit Text measures its own available container and derives a font size through WordPress core.
3. The title's optional Wordmark Width caps that title independently, but never exceeds the identity container.
4. The tagline rules flex to fill the same identity width.
5. Style Manager and Global Styles continue to provide font family, weight, case, tracking, line height, and contextual color.

## Accessibility and Failure Modes

- The title remains a real heading and link generated by `core/site-title`.
- The decorative tagline rules use pseudo-elements and add no accessibility-tree noise.
- No text is duplicated to perform measurement.
- Without Fit Text JavaScript, the title keeps normal CSS typography and remains readable.
- Long titles are width-constrained; the Wordmark style deliberately keeps them on one line and core reduces their fitted size.
- Empty or removed taglines leave a valid Site Identity containing only the Site Title.

## Verification

- Contract tests cover server metadata, sanitization, and rendered width output.
- JavaScript tests cover the core block extension, width state, styles, and header recipe.
- The package build verifies source integration and generated assets.
- Browser checks cover the Site Editor and the frontend at desktop and narrow widths.
